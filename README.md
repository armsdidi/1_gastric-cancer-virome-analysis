# Characterization of the Gastric Virome Using RNA-Seq Data
This repository contains Shell and R scripts for characterizing the gastric cancer-associated virome and investigating its relationships with clinicopathological features using metatranscriptomic RNA-Seq data.

The analysis workflow includes viral taxonomic classification, viral composition and relative abundance analyses, alpha and beta diversity, community profiling and clustering, differential abundance analysis, and characterization of EBV transcriptional patterns.

The main bioinformatics tools and R packages used include Kraken2, Pavian, phyloseq, microbiome, vegan, microbiomeMarker, ggplot2, circlize, ComplexHeatmap, ade4, cluster, philentropy, and factoextra.
